Optional. Keeps this calendar identical on every device where you switch it on, using one private file in your own GitHub repository. Nothing changes until you save below, and a safety copy is made before this device's data is ever changed.

One-time GitHub setup

  1. Create a private repository, e.g. ghibli-calendar-data.
  2. GitHub → Settings → Developer settings → Fine-grained tokens → new token. Repository access: only that repo. Permission: Contents → Read and write.
  3. Fill in the form below on each device.
Disconnecting only stops syncing. Your calendar data stays on this device.
